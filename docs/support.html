Bounded result caching, structured diagnostics, secrets, views, globals, and split-plan reuse are wired; publishing, long-lived failure coverage, and the explicit compatibility gaps below remain.

Table caching

Worker-opted-in results use a bounded session-memory cache, and embedders may add a host-owned durable tier for complete bounded producer and split scans.

  • Worker connections, attach handles, table binds, and scalar return types are reused.
  • Complete ordinary and split scans commit atomically; errors, cancellation, abandoned LIMITs, and incomplete partitions never store partial rows.
  • Keys isolate auth identity, catalog/version, arguments, attach options, typed session settings, remotely applied query shape, and limit. Advertised projection/filter pushdown stays in the key; explicitly local shape does not; unknown legacy filter behavior remains conservatively keyed.
  • Workers without projection pushdown share one cached full result across local projections; every replay is conformed to the requested schema, including zero-column count(*).
  • ETag/Last-Modified revalidation, stale-if-error, and per-key single-flight work for producer entries, stateless table-input batches, stable scalar per-value entries, and buffered whole-input results.
  • Immediate-stale validators revalidate instead of bypassing. If the worker withdraws eligibility with no_store, transaction scope, or per-value revocation, stale bytes are evicted rather than replayed.
  • Buffered keys are duplicate-preserving input multisets, so row order and physical batch boundaries do not cause false misses. Ordered sinks, cancellation, lifecycle errors, and over-cap captures never commit.
  • Secret-dependent calls bypass caches. Live SQL limits bound memory-tier per-entry bytes, total bytes, and entry count; reductions evict entries that no longer fit and RESET restores constructor values.
  • The optional durable tier stores complete bounded catalog-scoped producer and split results as Arrow IPC using a host-selected codec (Zstandard by default). Non-split producer validators survive restart and support conditional refresh, stale-if-error, and exact-generation revocation. Split validators replay only after serial unanimous all-group agreement; fresh, mixed, or revoked votes trigger an unconditional whole-result rerun, and validation errors fail closed. Ordered split plans remain excluded. Atomic refs, capture/replay leases, corruption-as-miss recovery, restart reconciliation, and constructor-owned committed-payload admission limits support concurrent local processes.
  • Durable limits are not a hard filesystem quota: metadata and active temporary captures are excluded, each concurrent capture has its own byte cap, and processes sharing a root should use the same options.
  • Conditional revalidation and stale-if-error work for durable non-split producers. Single-flight remains runtime-local: durable locks protect publication and integrity, but separate cold processes may both invoke the worker before one generation wins.
  • Bounded non-split producer entries in memory honor worker stale-while-revalidate under an effective RPC timeout: callers receive stale rows immediately while one runtime-local background flight conditionally refreshes or revokes the entry. Durable, split, scalar, exchange, correlated 1:N, dynamic-filtered, unbounded, and secret-dependent SWR/cache entries remain unwired. Durable recency is approximate per process, and crash safety requires a local Unix filesystem with advisory locks, atomic rename, and directory fsync.
  • Inspect with vgi_cache_stats(), vgi_cache_entries(), and vgi_plan_cache_stats(). Disk counters/LRU touches are instance-local; occupancy scans the shared root. Durable revalidation capability and aggregate revalidation/stale-serve counters are reported; per-entry disk hits remain unavailable. Disk bytes are encoded payload, and disk substreams are stored partition files. Durable SQL inspection and maintenance perform blocking filesystem work.
  • Maintain both configured tiers with vgi_cache_flush() and vgi_cache_reap(). Flush removes lookup refs immediately; leased replay objects disappear after release and a later reap.
  • Read the code-backed cache phases and full implementation inventory →

Logging

Worker text and structured adapter lifecycle events are both visible.

  • DataFusion routes in-band worker logs from built-in subprocess, Unix, TCP, and HTTP connections to severity-specific worker.log.* session events. A standalone vgi-client uses Rust's log facade under target vgi::worker when no embedding sink is installed.
  • Structured extras are preserved as JSON text; exception batches become query errors.
  • Attach, plan, scan, cancellation, error, cache, buffered begin/combine/finalize, actual scalar writes, and streaming table-input sends go to an embedder VgiEventSink and a bounded session history. Structural counts are recorded without argument values or secrets.
  • Query history with vgi_logs() and vgi_log_stats(); clear it with vgi_logs_clear(). Worker text and structured extras are included in SQL history and the embedder sink.
  • In-band text and extras are untrusted, worker-controlled payloads retained verbatim. The adapter does not redact them and cannot guarantee that a worker will not log sensitive values. Worker-originated RPC, exception, and error text retained in error diagnostics has the same trust boundary.
  • Worker log messages do not yet carry request or function identifiers. Worker access logs and subprocess stderr are separate operator-facing channels and are not forwarded.

Capability matrix

What maps today

“Partial” means the protocol or Rust client has more capability than the DataFusion adapter currently exposes—not that the supported subset is experimental.

Catalog & connectivity
ATTACH / DETACH
Supported
DuckDB-style and query-string forms, typed worker options, cache/global-function policy, a positive per-attach rpc_timeout, and VGI-only companion attachments are supported. DETACH removes only alias-owned registrations.
Catalog discovery
Supported
vgi_catalogs(location) exposes the canonical VGI catalog schema before ATTACH. Attached schemas, tables, views, table/scalar/aggregate functions, scalar and table SQL macros, and nominated globals are then discovered and registered.
Native format branches
Supported
Worker-nominated CSV, Parquet, JSON/NDJSON, and Arrow scan arms use DataFusion's registered file-format factories and listing providers. Typed options, schema reconciliation, exact CSV null markers, and eligible native filter pushdown are preserved. Non-loopback workers need an explicit trust opt-in before they may nominate client-local paths.
Catalog-table branches
Supported
Companion source arms resolve existing DataFusion providers by attachment alias or unique worker-catalog identity, reuse reconciliation and filter pushdown, and reject direct or indirect source cycles.
SQL metadata
Supported
DataFusion SHOW TABLES, SHOW COLUMNS, SHOW FUNCTIONS, and information_schema expose VGI relations, schemas, columns, views, and routines. Catalog schemas come directly from discovery; scan functions bind only when queried.
Constraint metadata
Partial
VGI primary-key and unique constraints feed DataFusion's native provider constraint API. DataFusion has no native check, foreign-key, standalone NOT NULL, or DuckDB-compatible duckdb_constraints() metadata table.
Transports
Supported
Bare subprocess commands, HTTP, Unix sockets, TCP, and shared launch: workers use the same LOCATION spelling as DuckDB. HTTP, Unix, and TCP honor session or ATTACH RPC deadlines. Subprocess response reads do as well, killing and poisoning a timed-out child so the pool cannot reuse it; a blocked anonymous-pipe request write remains uninterruptible in Rust's standard library. Focused Unix/HTTP tests cover bounded backpressure, LIMIT cancellation, expired-split recovery, and post-timeout reuse. The HTTP blocking-dispatch and subprocess response-deadline fixes are released in vgi-rpc 0.23.3 and vgi-rust 0.31.0.
Connection pooling
Supported
Each DataFusion scan partition gets an independent VGI connection; idle connections and attach handles are reused. Failed producer open/header/read/cancel paths poison their client so a desynchronized connection is discarded, while natural EOS stays reusable.
Authentication
Supported
HTTP attaches recover from 401 via RFC 9728 discovery and OAuth device flow, or accept bearer_token / oauth_refresh_token. Adapter-owned credential fields are redacted and session-only; authentication is single-flight across partitions and isolated in the pool. Worker-originated error text remains untrusted.
Worker secrets
Supported
An embedder-installed async VgiSecretResolver drives one-retry scoped binds and statically declared aggregate secrets. The adapter does not copy resolved values into SQL, cache keys, or its constructed structural diagnostics, and secret-dependent calls bypass caches so resolver rotation cannot replay stale credential-derived results. Worker-originated log, RPC, exception, and error text is retained verbatim and remains outside that guarantee.
Session settings
Supported
Worker declarations become a dynamic DataFusion vgi.* ConfigExtension. Native and unqualified SET, RESET, scalar and JSON-to-Struct values, duckdb_settings(), and settings-aware cache isolation are covered over Unix and HTTP. Adapter-owned scalar dedup, per-value-cache veto, and three live cache memory bounds use the same SQL surface.
Table time travel
Supported
Fully-qualified VGI catalog tables accept literal AT (VERSION => …) and AT (TIMESTAMP => …). Historical schema evolution is planned correctly, the coordinate reaches bind/plan/scan, and result plus split-plan caches isolate each coordinate.
Transactions & snapshot pinning
Not wired
DataFusion transaction statements are not bridged to VGI, and there is no catalog-wide snapshot pinning lifecycle.
Functions & SQL
Producer table functions
Supported
Constant positional and named arguments bind through DataFusion table functions, including catalog scan functions.
Scalar functions
Supported
Async scalar UDFs execute columnar batches; const parameters are separated at bind, output types are memoized, and overload selection preserves VGI type-family compatibility. Untyped NULL varargs adopt a type only from identical concrete peers; mixed/all-null calls remain worker-authoritative. Stable input tuples are deduplicated and gathered back in caller order; volatile calls bypass dedup. The scalar/overload corpus executes 565/565 applicable records.
Aggregate functions
Partial
Grouped aggregates and bind-time ConstParams are correct, but inputs are buffered locally per group because VGI aggregate state cannot be serialized across DataFusion's partial/final stages.
Scalar & table SQL macros
Supported
Qualified catalog macros expand locally into existing DataFusion expressions or derived relations. Typed defaults, positional and named arguments, same- and cross-schema worker references, nested scalar expansion, and deterministic recursion errors are supported.
Views & global functions
Supported
Worker view SQL is qualified and installed as DataFusion ViewTables. Nominated scalar, aggregate, table, and buffered globals are default-on with global_functions false opt-out; first owners win collisions, concurrent attaches are linearized, and DETACH/replacement preserves native or newer owners.
Window aggregates
Partial
Advertised sliding aggregates use the dedicated VGI window callback through DataFusion's sliding-accumulator API. Each accumulator retains one worker connection and bind across its frames, including the 5,000-row HTTP corpus case; ordinary grouping keeps aggregate update/finalize semantics. DataFusion 55 does not support window EXCLUDE or aggregate-local ORDER BY forms.
Table-in/out & buffered
Partial
Literal blended calls and buffered/exchange functions work. Finite LIMIT uses an incremental, cancellable exchange rather than materializing the whole child; the HTTP 100-million-row LIMIT 5 regression completes in 0.16 seconds. One input column can carry nested Arrow maps, structs, lists, fixed-size lists, dictionaries, temporal, decimal, and binary values. Multiple top-level input columns, Arrow Union, and DuckDB BIT construction remain DataFusion SQL/planning boundaries.
Correlated LATERAL calls
Not wired
DataFusion binds a table function before outer rows exist, so LATERAL forecast(g.latitude, g.longitude) still requires a two-step query.
EXPLAIN
Supported
The VGI rewrite now traverses DataFusion's EXPLAIN wrapper, including named table-function arguments and Unicode macro expressions.
Set operations, CTEs & joins
Supported
VGI scans compose through DataFusion's existing UNION/INTERSECT/EXCEPT, IN/EXISTS, CTE, and semi/anti plans. The adapter maps DuckDB's unqualified SEMI JOIN/ANTI JOIN spelling to the equivalent left-directed plans. Correlated scalar subqueries containing VGI aggregates remain a DataFusion 55 physical-planning boundary.
Optimizer & execution
Projection & LIMIT pushdown
Supported
Projected columns and row limits reach bind, split planning, and scan. Empty projection for count(*) uses the narrowest physical column.
Static filter pushdown
Supported
Supported predicates preserve their Arrow scalar types when serialized for VGI. Same-column equality OR trees and IN use join-key side IPC. Direct table functions preserve exact worker application; lazy catalog tables conservatively recheck. The typed corpus executes 185/185 applicable records with every comparable result agreeing.
Required filters
Supported
Catalog-table AND-of-OR requirements are enforced before scan. Struct paths remain precise, parent predicates satisfy descendants, and both transports pass all 45 applicable reviewed records with 25 exact result checks.
Split planning
Supported
Pagination, max-workers enforcement, byte-weighted bin packing, zero/empty splits, execution context, and independent split redemption are covered.
Statistics
Supported
Catalog-inlined estimate/max, plan and split row/byte estimates, per-column statistics, and partition bounds feed DataFusion's provider and physical StatisticsContext APIs with appropriate exactness. Historical scans do not reuse current-table cardinality.
Ordering & Top-N hints
Supported
Within-split ordering is advertised when each physical partition owns exactly one split. An opt-in DataFusion 55 planner bridge maps safe direct-column ORDER BY ... LIMIT/OFFSET shapes into advisory VGI split-plan and scan hints, with cache isolation. DataFusion retains its Sort/Top-K and limit semantics for correctness; computed expressions stay local, and filters or multi-key ordering suppress the worker early-stop limit.
Positions & streaming
Partial
Start-only plans now declare honest DataFusion unbounded output. Checkpoint/reconnect policy and advertised resume gating still need production hardening.
Locality & partition transforms
Partial
Location hints are exposed through an embedder scheduler hook, and bounds feed statistics. VGI hash transforms are not assumed to match DataFusion partition semantics.
Dynamic filters & join keys
Partial
DataFusion 55 runtime filters are linked to VGI scans. Single-column join sets use version-2 join-key side IPC at init; small multi-column hash-join tuple sets are sent as safe per-column marginals while DataFusion keeps the exact tuple join locally. Later constant/range generations use base64 vgi_pushdown_filters across subprocess, Unix/TCP, and plain or authenticated HTTP continuations. Large hash/Bloom state and tuple-correlated protocol expressions remain local, and dynamic scans bypass result caching.
Table sampling
Supported
DataFusion 55's relation-planner API maps TABLESAMPLE SYSTEM percentage and repeatable seed into VGI split planning and scan initialization. Plan and result cache identities include the exact hint; host-owned Bernoulli sampling is not sent as a VGI SYSTEM hint.
Cancellation
Partial
Dropping an unfinished scan consumer, dropping the client scan itself, or satisfying a LIMIT sends protocol cancellation; cleanup failures poison pooled clients. HTTP, Unix, and TCP blocking phases honor rpc_timeout. Subprocess response reads also honor it and poison a timed-out child, but a blocked anonymous-pipe request write and cooperative mid-call DataFusion task interruption remain unavailable.
Caching, observability & mutation
Planning / metadata cache
Supported
Attach handles, binds, return types, and connections are memoized. Catalog-scoped split plans reuse the worker's advertised maximum age and catalog-version identity.
VGI result cache
Partial
Bounded session memory covers producer/split scans, stateless streaming input batches, worker-opted stable scalar values, and unordered buffered whole-input results with validators, stale-if-error, and runtime-local single-flight. Bounded non-split memory producers also honor stale-while-revalidate under an effective RPC timeout, serving immediately while one background flight refreshes. An optional host-owned tier persists complete bounded producer/split results as Arrow IPC with a configured codec (Zstandard by default) and shares them across local processes using atomic refs, leases, restart reconciliation, corruption-as-miss recovery, and constructor-owned limits. Non-split producer validators persist across restart with conditional refresh, stale-if-error, and exact-generation revocation. Split validators replay only after unanimous serial all-group agreement; fresh, mixed, or revoked votes trigger an unconditional whole-result rerun and validation errors fail closed. Exact tier events and combined SQL diagnostics, flush, and reap are exposed. Durable exchange/scalar/correlated, dynamic-filtered, unbounded, and secret-dependent entries plus durable/split/exchange/scalar SWR remain unwired; cross-process locks do not coalesce worker calls, recency is approximate per process, and crash safety requires local Unix filesystem semantics.
Worker execution profiling
Supported
With the VGI session-builder extension, a clean worker scan under EXPLAIN ANALYZE invokes VGI dynamic_to_string after cache publication and appends escaped, bounded, partition-labelled diagnostics to the scan metrics. Ordinary queries, plain EXPLAIN, failed or cancelled/LIMIT-shortened scans, and cache replays skip the callback. The planner bridge composes with ORDER BY/Top-N propagation.
Structured logs
Supported
DataFusion routes in-band worker logs from built-in subprocess, Unix, TCP, and HTTP connections to bounded SQL-visible history, grouped stats, and the embedder event sink; a standalone vgi-client defaults to vgi::worker. Worker-controlled logs and worker-originated RPC/exception/error text retained in diagnostics are untrusted. Request/function correlation, worker access logs, and subprocess stderr are not forwarded.
Writes, DDL & COPY
Not wired
INSERT, UPDATE, DELETE, writable branches, catalog DDL, custom COPY formats, and SQL CREATE SECRET integration are not wired.

Implementation backlog

What is left

Ordered by what most improves operability and real workloads. Each card names an implementation boundary, not just a broad feature wish.

01 · Ship

Publish and distribute

Turn the working local integration into a reproducible artifact rather than a sibling-checkout build.

  • Publish vgi-datafusion against DataFusion 55.
  • Upstream or maintain the small DataFusion CLI integration patch.
  • Add release CI and packaged CLI artifacts.
02 · Cache

Extend the result cache

Memory tiers share conditional policy handling, while complete bounded producer results can use the new durable Arrow IPC tier; add breadth only where VGI and DataFusion have matching semantics.

  • Extend the bounded non-split producer SWR contract only where equivalent timeout, single-flight, and atomic replacement semantics exist.
  • Add correlated 1:N entries only with complete keys and explicit cancellation boundaries.
  • Evaluate durable scalar and exchange entries only after defining compact per-value packing and cancellation-safe whole-input keys.
03 · Operate

Finish observability edges

Lifecycle/cache events and in-band worker logs are queryable; host tracing can still be joined more tightly.

  • Add query/execution IDs supplied by embedders.
  • Define whether access logs or subprocess stderr need a separate operator integration.
  • Add deadline and stalled-worker coverage for every transport.
04 · Boundary

Keep correlated LATERAL explicit

DataFusion does not expose an outer row to its table-function bind seam, so the one-statement geocode-to-forecast form remains outside this adapter's no-new-engine-work scope.

  • Use a two-step query or host orchestration today.
  • Revisit only if upstream DataFusion exposes an execution-time table-function API.
  • Do not add an adapter-owned query operator solely for this syntax.
05 · Secure

CLI secret mappings

The embedder resolver and VGI bind protocol are wired; the stock CLI still needs an explicit environment-to-secret mapping surface.

  • Map named environment variables to typed secret fields without reading arbitrary process environment.
  • Keep refresh-token persistence an explicit opt-in.
  • Add scoped multi-secret CLI tests.
06 · Interrupt

End-to-end cancellation

Active scans cancel and network/socket RPC deadlines are configurable; cooperative interruption still has narrower boundaries.

  • Add a recoverable deadline/cancellation mechanism for subprocess pipe RPCs.
  • Propagate DataFusion task cancellation into connect, attach, bind, and plan calls rather than relying only on deadlines.
  • Extend stalled-worker and cancellation soak coverage around unbounded scans.
07 · Optimize

Broaden runtime hints safely

SYSTEM sampling and advisory direct-column ORDER BY/Top-N now cross existing DataFusion planner boundaries.

  • Keep computed and unsafe multi-key early-stop shapes local unless VGI gains a richer ordering contract.
  • Represent large hash-lookup and tuple-correlated multi-column dynamic filters; safe per-column marginals already prune small joins.
  • Use locality only when a scheduler-affinity contract exists.
08 · Generalize

Richer table input

Remove the scalar-subquery restriction that limits exchange functions to one input column.

  • Represent multi-column table arguments in the logical plan.
  • Preserve schema and partitioning through buffered/exchange calls.
  • Cover wide, empty, and multi-partition inputs.
09 · Stream

Harden unbounded splits

Plans now declare unbounded output; make long-lived execution recoverable.

  • Gate resume on worker advertisement.
  • Define checkpoints, reconnects, and cancellation.
  • Add soak and backpressure tests.
10 · Deferred

Writes and transactions

These protocol surfaces remain outside the current read/query-focused scope.

  • INSERT, UPDATE, DELETE, DDL, and COPY are not active implementation work.
  • Transaction lifecycle and catalog-version pinning remain future design topics.
  • Table-level read-only time travel is already supported.
